# Radar estratégico — wp24h-md-importer — 17/08/2026

## P1 — WordPress 7.1 entra amanhã no dry run e o plugin ainda declara compatibilidade até 7.0

### O que aconteceu
O cronograma oficial do WordPress 7.1 mantém o **dry run e congelamento de código de 24 horas em 18/08/2026 às 15:00 UTC**, com release final previsto para **19/08/2026**.

O `readme.txt` deste plugin ainda declara:

```text
Requires at least: 6.5
Tested up to: 7.0
Requires PHP: 7.4
Stable tag: 1.2.0
```

### Impacto específico no projeto
Este plugin automatiza criação e atualização de posts a partir de Markdown/YAML, expõe uma REST API opcional e faz sideload de imagem destacada usando APIs do WordPress. A proximidade da release torna a compatibilidade uma ação verificável agora.

O metadado `Tested up to` não deve ser atualizado apenas para acompanhar a versão do Core: ele deve refletir teste real.

### Risco / oportunidade
- **Risco:** médio/alto — afirmar compatibilidade sem teste pode gerar regressões e suporte reativo logo após o lançamento.
- **Oportunidade:** alta — validar antes do release permite publicar uma versão realmente testada e gerar conteúdo técnico útil para o WP24Horas.

### Ação recomendada
Executar um gate curto contra WordPress 7.1 RC2:

1. ativação/desativação sem fatal ou warning novo;
2. importação Markdown com front matter mínimo e completo;
3. criação e atualização por slug;
4. categorias, tags e SEO metadata;
5. endpoint REST desabilitado e habilitado;
6. autenticação por Application Password/REST normal;
7. usuário sem `publish_posts` e sem `upload_files`;
8. sideload de imagem remota, redirect e reutilização de attachment existente;
9. payload acima do limite e entradas inválidas;
10. logs PHP e respostas REST sem regressões.

Somente após esse gate passar, alterar `Tested up to: 7.1`. Se houver qualquer incompatibilidade, preparar patch release antes de atualizar o metadado.

O `cnaf-wp-docker` pode ser usado como laboratório reproduzível para o teste, reduzindo o custo de repetir a mesma matriz em releases futuras.
