# Radar estratégico — wp24h-md-importer — 18/08/2026

## P1 — O dry run do WordPress 7.1 é hoje e o plugin ainda declara compatibilidade até 7.0

### O que aconteceu
O cronograma oficial do WordPress 7.1 mantém para **hoje, 18/08/2026 às 15:00 UTC (12:00 no horário de Brasília)**, o dry run da release e o congelamento de código de 24 horas. A versão final está programada para **19/08/2026**.

O `readme.txt` deste repositório ainda declara:

```text
Requires at least: 6.5
Tested up to: 7.0
Requires PHP: 7.4
Stable tag: 1.2.0
```

### Impacto específico no projeto
A situação mudou desde o radar de ontem: a janela de validação não é mais “antes de amanhã”; ela termina operacionalmente hoje. O plugin toca criação/atualização de posts, taxonomias, metadados, REST API opcional e sideload de mídia — áreas que precisam de smoke test real antes de afirmar compatibilidade com 7.1.

O WordPress 7.1 também avança o editor sempre em iframe e traz mudanças em mídia e APIs que tornam especialmente importante validar fluxos que dependam de admin/editor, JavaScript ou comportamento de upload, mesmo que o importador em si seja predominantemente PHP.

### Risco / oportunidade
- **Risco:** médio/alto — release do Core iminente com `Tested up to` ainda em 7.0 e sem evidência versionada de validação 7.1 neste repositório.
- **Oportunidade:** alta — transformar o teste em evidência pública de compatibilidade e em conteúdo técnico para o WP24Horas.

Executar hoje um gate curto contra WordPress 7.1 RC2, usando ambiente descartável ou o `cnaf-wp-docker`:
