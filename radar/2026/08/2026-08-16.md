# Radar estratégico — wp24h-md-importer — 16/08/2026

## P0 — Validar compatibilidade com WordPress 7.1 antes do release

### O que aconteceu
O WordPress 7.1 está na janela final de release, com dry run em 18/08/2026 e lançamento final previsto para 19/08/2026. O ciclo inclui mudanças em APIs e comportamento do editor que justificam smoke tests em plugins próprios.

### Impacto específico
Como este plugin importa conteúdo Markdown para WordPress e pode tocar fluxo editorial, mídia, REST/AJAX, metadados e telas administrativas, uma regressão após atualização do Core pode interromper o pipeline de publicação.

### Risco / oportunidade
- **Risco:** alto até existir teste contra WordPress 7.1 RC/final.
- **Oportunidade:** transformar o plugin em referência pública de compatibilidade e boas práticas para o WP24Horas.

### Ação recomendada
Executar smoke tests cobrindo:
1. instalação/ativação;
2. importação de Markdown;
3. criação/atualização de posts e metadados;
4. mídia e featured image, se aplicável;
5. REST/AJAX e permissões;
6. telas administrativas;
7. logs PHP e console sem novos erros.

Depois do release final, repetir a suíte na versão estável e registrar compatibilidade no README/changelog.
